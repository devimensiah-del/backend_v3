# Plan 05-01: Remove Dead Code and Fix Comments

**Phase:** 05-cleanup
**Plan:** 01 of 03
**Status:** Blocked
**Depends:** Phase 3 complete (report removal done)

---

## Objective

Remove dead code, fix outdated comments, and clean up unused imports.

---

## Context

**Identified dead code (from audit):**
- `api/submission_response_builder.go` - Report status building (dead after report removal)
- Outdated comments referencing "11 frameworks" or "4-model approach"
- Potential unused adapter code in main.go

**Why this matters:** Dead code confuses maintainers and increases cognitive load.

---

## Tasks

### Task 1: Scan for unused code
**Type:** verify
**Files:** All Go files
**Action:**
```bash
# Find unused functions
go vet ./...

# Find unused imports
goimports -l .

# Check for dead code (if staticcheck installed)
staticcheck ./...
```

Document all findings.

**Verify:** Capture list of issues

---

### Task 2: Clean submission response builder
**Type:** modify
**Files:** `api/submission_response_builder.go`
**Action:**
Remove any report-status related code that's now dead:
- Remove `buildReportStatus()` if exists
- Remove report_status from response structs
- Remove report-related helper functions

**Verify:** `go build ./api/...`

---

### Task 3: Update workflow comments
**Type:** modify
**Files:** `domain/analysis/workflow.go`
**Action:**
Update or remove outdated comments:
```go
// CHANGE FROM:
// "11 frameworks are executed in layers"
// TO:
// "Frameworks are loaded from database and executed in dependency order"
```

**Verify:** Read through file, confirm accuracy

---

### Task 4: Update config comments
**Type:** modify
**Files:** `config/config.go`
**Action:**
Update model configuration comments:
```go
// CHANGE FROM:
// "4-model approach via OpenRouter"
// TO:
// "6-model approach with fallbacks via OpenRouter"
// (or whatever the current count is)
```

**Verify:** Comments match reality

---

### Task 5: Remove PRODUCTION FIX comment
**Type:** modify
**Files:** `main.go`
**Action:**
If the fix is stable (line ~404), remove the temporary comment:
```go
// DELETE: // PRODUCTION FIX - temporary workaround for...
```

Only if the fix is now permanent.

**Verify:** `go build .`

---

### Task 6: Clean up unused imports
**Type:** modify
**Files:** All Go files
**Action:**
```bash
goimports -w .
```

This automatically removes unused imports and fixes formatting.

**Verify:** `go build ./...`
