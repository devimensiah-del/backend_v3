# Plan 05-02: Standardize Naming Conventions

**Phase:** 05-cleanup
**Plan:** 02 of 03
**Status:** Blocked
**Depends:** 05-01 (dead code removed first)

---

## Objective

Standardize naming conventions across the codebase.

---

## Context

**Inconsistencies found (from audit):**
- `reportLookupAdapter` (lowercase) should be `ReportLookupAdapter` if exported
- Repository naming: `PostgresRepository` vs `NewRepository` inconsistent
- Some adapters in main.go instead of adapter/ package

**Standards to apply:**
- Structs: PascalCase, noun
- Interfaces: PascalCase, "-er" suffix or descriptive
- Methods: PascalCase exported, camelCase internal
- Variables: camelCase
- Constants: PascalCase or SCREAMING_SNAKE for env vars

---

## Tasks

### Task 1: Audit current naming
**Type:** verify
**Files:** All Go files
**Action:**
Create inventory of naming patterns:
```bash
# Find struct definitions
grep -r "type.*struct" . --include="*.go"

# Find interface definitions
grep -r "type.*interface" . --include="*.go"

# Find unexported types that should be exported
grep -r "type [a-z].*struct" . --include="*.go"
```

**Verify:** List created

---

### Task 2: Move adapters to adapter package
**Type:** refactor
**Files:** `main.go`, `adapter/`
**Action:**
Move adapters from main.go to proper package:
```go
// Move macroServiceAdapter to adapter/macro_adapter.go
// Move any remaining adapters

// main.go changes:
// FROM: macroAdapter := macroServiceAdapter{svc: macroSvc}
// TO:   macroAdapter := adapter.NewMacroAdapter(macroSvc)
```

**Verify:** `go build .`

---

### Task 3: Standardize repository constructors
**Type:** modify
**Files:** `domain/*/repository.go`
**Action:**
Ensure consistent naming:
```go
// All repositories should use:
type Repository interface { ... }  // Interface
type PostgresRepository struct { ... }  // Implementation
func NewPostgresRepository(db *sqlx.DB) *PostgresRepository  // Constructor
```

Check each domain package.

**Verify:** `go build ./domain/...`

---

### Task 4: Standardize service constructors
**Type:** modify
**Files:** `domain/*/service.go`
**Action:**
Ensure consistent naming:
```go
type Service struct { ... }
func NewService(repo Repository, logger zerolog.Logger) *Service
```

**Verify:** `go build ./domain/...`
