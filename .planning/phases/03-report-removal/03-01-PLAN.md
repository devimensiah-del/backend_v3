# Plan 03-01: Remove Report API Handlers and Routes

**Phase:** 03-report-removal
**Plan:** 01 of 05
**Status:** Blocked
**Depends:** Phase 2 (analysis handles all report data)

---

## Objective

Remove all report-related API handlers and routes.

---

## Context

@file:api/report_handlers.go - Handlers to delete
@file:api/router.go - Routes to remove
@file:api/handlers.go - Handler struct to update

**Why this matters:** Report endpoints are the public interface. Removing them first signals the deprecation clearly.

**Breaking Change Warning:** Frontend must be updated to stop calling report endpoints.

---

## Tasks

### Task 1: Coordinate with frontend
**Type:** coordination
**Files:** N/A
**Action:**
Verify frontend has been updated to:
- NOT call `/api/v1/submissions/:id/report`
- NOT call `/api/v1/admin/reports/*`
- Use analysis endpoints for PDF data instead

**Checkpoint:** human-verify
Confirm frontend changes are deployed or not needed.

---

### Task 2: Remove routes from router
**Type:** modify
**Files:** `api/router.go`
**Action:**
Remove all report route registrations:
```go
// DELETE these lines:
// v1.GET("/submissions/:id/report", h.Report.GetReport)
// admin.GET("/reports", h.Report.AdminList)
// admin.POST("/reports/:id/generate", h.Report.TriggerGeneration)
// etc.
```

Comment out first, verify build, then delete.

**Verify:** `go build ./api/...`

---

### Task 3: Remove ReportHandlers from Handler struct
**Type:** modify
**Files:** `api/handlers.go`
**Action:**
Remove ReportHandlers field:
```go
type Handler struct {
    // ... other handlers
    // Report *ReportHandlers  // REMOVE
}
```

Update NewHandler to not require report handlers parameter.

**Verify:** `go build ./api/...`

---

### Task 4: Delete report handlers file
**Type:** delete
**Files:** `api/report_handlers.go`
**Action:**
Delete the entire file.

**Verify:** `go build ./api/...`

**Verify:** `go build ./api/...`
