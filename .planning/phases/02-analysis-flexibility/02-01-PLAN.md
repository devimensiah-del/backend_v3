# Plan 02-01: Add framework_results JSONB Column

**Phase:** 02-analysis-flexibility
**Plan:** 01 of 04
**Status:** Blocked (needs Phase 1 complete)
**Depends:** Phase 1 (framework service exists)

---

## Objective

Add `framework_results JSONB` column to analyses table for generic framework storage.

---

## Context

@file:domain/analysis/model.go - Current 11 separate JSONB columns
@file:domain/analysis/repository.go - Current INSERT/UPDATE with 11 columns
@file:migrations/028_analyses_pdf_columns.sql - Migration pattern

**Why this matters:** The 11 separate columns lock the schema to specific frameworks. A single JSONB map enables dynamic frameworks.

---

## Tasks

### Task 1: Create migration for new column
**Type:** create
**Files:** `migrations/034_add_framework_results.sql`
**Action:**
```sql
-- Add generic framework results column
ALTER TABLE analyses
ADD COLUMN IF NOT EXISTS framework_results JSONB DEFAULT '{}';

-- Index for querying specific frameworks
CREATE INDEX IF NOT EXISTS idx_analyses_framework_results
ON analyses USING gin(framework_results);

-- Comment explaining the structure
COMMENT ON COLUMN analyses.framework_results IS
'Generic storage for all framework results. Structure: {"pestel": {...}, "swot": {...}, ...}';
```

**Verify:** SQL syntax valid
