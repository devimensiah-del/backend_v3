## Tasks

### Task 1: Create data migration script
**Type:** create
**Files:** `migrations/035_migrate_framework_results.sql`
**Action:**
```sql
-- Migrate existing framework data to framework_results column
UPDATE analyses
SET framework_results = jsonb_build_object(
    'pestel', COALESCE(pestel, 'null'::jsonb),
    'porter', COALESCE(porter, 'null'::jsonb),
    'swot', COALESCE(swot, 'null'::jsonb),
    'tam_sam_som', COALESCE(tam_sam_som, 'null'::jsonb),
    'benchmarking', COALESCE(benchmarking, 'null'::jsonb),
    'blue_ocean', COALESCE(blue_ocean, 'null'::jsonb),
    'growth_hacking', COALESCE(growth_hacking, 'null'::jsonb),
    'scenarios', COALESCE(scenarios, 'null'::jsonb),
    'okrs', COALESCE(okrs, 'null'::jsonb),
    'bsc', COALESCE(bsc, 'null'::jsonb),
    'decision_matrix', COALESCE(decision_matrix, 'null'::jsonb)
)
WHERE framework_results IS NULL OR framework_results = '{}'::jsonb;
```

**Verify:** SQL syntax valid

**Checkpoint:** human-verify
Run migration on staging, verify data integrity before dropping columns.
