### Task 2: Create dynamic execution function
**Type:** modify
**Files:** `domain/analysis/workflow.go`
**Action:**
Add new execution method that uses framework service:
```go
func (s *Service) executeFrameworkDynamic(
    ctx context.Context,
    fw *framework.Framework,
    enrichmentData map[string]interface{},
    previousResults map[string]json.RawMessage,
) (json.RawMessage, error) {
    // Build prompt from framework template
    prompt := s.buildPromptFromTemplate(fw.PromptTemplate, enrichmentData, previousResults)

    // Call LLM with framework-specific settings
    opts := llm.GenerateOptions{
        Model:       fw.PreferredModel, // or default
        Temperature: fw.Temperature,
        Timeout:     time.Duration(fw.TimeoutSeconds) * time.Second,
    }

    // Generate and parse according to output schema
    result, err := s.llmClient.GenerateStructuredWithOptions(ctx, prompt, fw.OutputSchema, opts)
    return result, err
}
```

**Verify:** `go build ./domain/analysis/...`

### Task 3: Create new RunAnalysisDynamic method
**Type:** modify
**Files:** `domain/analysis/workflow.go`
**Action:**
```go
func (s *Service) RunAnalysisDynamic(
    ctx context.Context,
    analysisID string,
    enrichmentData map[string]interface{},
    requestedCodes []string, // Optional: nil means all active
) error {
    // Get execution plan (handles dependencies)
    var codes []string
    if len(requestedCodes) > 0 {
        codes = requestedCodes
    } else {
        // Get all active framework codes
        activeFrameworks, _ := s.frameworkService.ListActive(ctx)
        for _, fw := range activeFrameworks {
            codes = append(codes, fw.Code)
        }
    }

    frameworks, err := s.frameworkService.GetExecutionPlan(ctx, codes)
    if err != nil {
        return err
    }

    results := make(map[string]json.RawMessage)

    // Execute in order (dependencies already resolved)
    for _, fw := range frameworks {
        result, err := s.executeFrameworkDynamic(ctx, fw, enrichmentData, results)
        if err != nil {
            return fmt.Errorf("framework %s failed: %w", fw.Code, err)
        }
        results[fw.Code] = result

        // Save incrementally
        s.repo.SetFrameworkResult(ctx, analysisID, fw.Code, result)
    }

    return nil
}
```

Keep existing RunAnalysis() as fallback during transition.

**Verify:** `go build ./domain/analysis/...`
