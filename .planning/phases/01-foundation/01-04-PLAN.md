## Tasks

### Task 1: Create framework handlers
**Type:** create
**Files:** `api/framework_handlers.go`
**Action:**
Create FrameworkHandlers struct with:
- List(c *gin.Context) - GET /api/v1/frameworks (public, active only)
- GetByCode(c *gin.Context) - GET /api/v1/frameworks/:code (public)
- AdminList(c *gin.Context) - GET /api/v1/admin/frameworks (admin, all)
- AdminCreate(c *gin.Context) - POST /api/v1/admin/frameworks (admin)
- AdminUpdate(c *gin.Context) - PUT /api/v1/admin/frameworks/:id (admin)
- AdminDeactivate(c *gin.Context) - DELETE /api/v1/admin/frameworks/:id (admin)

Response format matching existing API patterns:
```json
{
  "data": [...],
  "meta": { "total": 11 }
}
```

**Verify:** `go build ./api/...`

### Task 2: Register routes
**Type:** modify
**Files:** `api/router.go`
**Action:**
Add framework routes:
```go
// Public routes
v1.GET("/frameworks", h.Framework.List)
v1.GET("/frameworks/:code", h.Framework.GetByCode)

// Admin routes (in admin group)
admin.GET("/frameworks", h.Framework.AdminList)
admin.POST("/frameworks", h.Framework.AdminCreate)
admin.PUT("/frameworks/:id", h.Framework.AdminUpdate)
admin.DELETE("/frameworks/:id", h.Framework.AdminDeactivate)
```

**Verify:** `go build ./api/...`

### Task 4: Initialize in main.go
**Type:** modify
**Files:** `main.go`
**Action:**
Add framework service initialization:
```go
// After database connection
frameworkRepo := framework.NewPostgresRepository(db)

// Create handlers

// Pass to handler constructor

```
