# Plan 01-01: Framework Domain Package Structure

**Phase:** 01-foundation
**Plan:** 01 of 04
**Status:** Ready

---

## Objective

Create the `domain/framework/` package with model, repository interface, and service - the foundation for dynamic framework execution.

---

## Context

@file:domain/analysis/model.go - Current hardcoded framework structs (reference for fields)
@file:domain/submission/model.go - Example of domain model pattern
@file:domain/submission/repository.go - Example of repository pattern
@file:domain/submission/service.go - Example of service pattern

**Why this matters:** Currently 11 framework types are hardcoded in analysis/model.go. This package enables storing framework definitions in the database, making the system flexible.

---

## Tasks

### Task 1: Create framework model
**Type:** create
**Files:** `domain/framework/model.go`
**Action:**
Create Framework struct with:
- ID (uuid.UUID)
- Code (string, unique key like "pestel", "swot")
- Name, NamePT (string, display names)
- Description, DescriptionPT (*string, nullable)
- Category (string: "environment", "positioning", "strategy", "execution")
- LayerOrder (int, execution order within category)
- IsActive (bool)
- RequiresEnrichment (bool)
- TimeoutSeconds (int)
- PromptTemplate (string, LLM prompt with {{variables}})
- OutputSchema (json.RawMessage, JSON Schema)
- PreferredModel (*string, optional model override)
- Temperature (float64)
- DependsOn ([]string, framework codes)
- CreatedAt, UpdatedAt (time.Time)

Also create Category constants and validation methods.

**Verify:** `go build ./domain/framework/`

---

### Task 2: Create repository interface and Postgres implementation
**Type:** create
**Files:** `domain/framework/repository.go`
**Action:**
Create Repository interface with:
- GetByID(ctx, id) (*Framework, error)
- GetByCode(ctx, code) (*Framework, error)
- List(ctx, activeOnly bool) ([]*Framework, error)
- ListByCategory(ctx, category) ([]*Framework, error)
- Create(ctx, *Framework) error
- Update(ctx, *Framework) error
- Delete(ctx, id) error (soft delete via is_active = false)

Create PostgresRepository implementing the interface:
- Use sqlx patterns from existing repositories
- Support both *sqlx.DB and *sqlx.Tx
- Include proper error wrapping

**Verify:** `go build ./domain/framework/`

---

### Task 3: Create service with execution planning
**Type:** create
**Files:** `domain/framework/service.go`
**Action:**
Create Service struct with:
- repo Repository
- logger zerolog.Logger

Methods:
- GetByCode(ctx, code) (*Framework, error)
- List(ctx) ([]*Framework, error)
- ListActive(ctx) ([]*Framework, error)
- GetExecutionPlan(ctx, requestedCodes []string) ([]*Framework, error)
  - Resolves dependencies (DependsOn)
  - Returns frameworks in correct execution order
  - Validates all requested codes exist

Include topological sort for dependency resolution.

**Verify:** `go build ./domain/framework/`
