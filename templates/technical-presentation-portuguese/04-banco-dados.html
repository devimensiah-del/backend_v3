02 — Arquitetura de Dados

Banco de Dados

PostgreSQL gerenciado via Supabase com autenticação integrada

Supabase PostgreSQL Gerenciado + Auth + Storage
Estrutura de Tabelas
submissions
Ponto de entrada. Contém dados do formulário: nome da empresa, contato, desafio de negócio, CNPJ, setor, etc.
users
Gerenciado pelo Supabase Auth. Contém perfil do usuário, role (admin/user), e credenciais.
↓ 1:1 ↓
enrichments
Dados enriquecidos pela IA: perfil corporativo, contexto macro, tendências do setor. Armazenado como JSONB.
analyses
Resultados dos 11 frameworks estratégicos + síntese executiva. Cada framework em campo JSONB separado.
Características Técnicas
🔒
Row Level Security
Políticas RLS garantem que usuários só acessam seus próprios dados
📦
JSONB Flexível
Dados de enriquecimento e análise armazenados como JSON estruturado
🔗
Connection Pooling
PgBouncer integrado para otimizar conexões em produção
🔗
Códigos de Acesso
Códigos de 6 caracteres para compartilhamento público sem login
