# Coimma Strategic Analysis PDF Generation

## Overview

This directory contains a Go program that generates a professional PDF report from the Coimma strategic analysis using landscape A4 format (842px × 595px).

## Prerequisites

1. **Docker Desktop** must be running
2. **Gotenberg service** must be available at `http://localhost:3000`

## Quick Start

### Step 1: Start Gotenberg

```bash
# Start Gotenberg using docker-compose
docker-compose up -d gotenberg

# Verify Gotenberg is running
curl http://localhost:3000/health
```

### Step 2: Generate the PDF

```bash
# Navigate to integration_tests directory
cd integration_tests

# Run the PDF generation program
go run generate_coimma_pdf.go
```

### Step 3: View the PDF

The PDF will be generated at:
```
integration_tests/coimma_strategic_analysis.pdf
```

## Report Contents

The generated PDF includes:

1. **Cover Page** - Company overview with branding
2. **PESTEL Analysis** - Environmental factors (6 dimensions)
3. **Porter's 5 Forces** - Competitive analysis
4. **TAM/SAM/SOM** - Market sizing and growth projections
5. **SWOT Analysis** - Strengths, Weaknesses, Opportunities, Threats
6. **Blue Ocean Strategy** - ERRC framework
7. **Scenario Planning** - Optimistic, Realist, Pessimistic scenarios
8. **OKRs** - Objectives and Key Results
9. **Balanced Scorecard** - 4 perspectives (Financial, Customer, Internal, Learning)
10. **Executive Synthesis** - Conclusions and recommendations

## Format Specifications

- **Page Size**: A4 Landscape (297mm × 210mm / 11.7" × 8.27")
- **Dimensions**: 842px × 595px per page
- **Margins**: 0 (full bleed design)
- **Template**: v2 (premium design with gold accents)
- **Font**: System sans-serif (-apple-system fallback)

## Troubleshooting

### Error: "connection refused" or "Gotenberg not running"

**Solution**: Start Docker Desktop and run:
```bash
docker-compose up -d gotenberg
```

### Error: "docker-compose: command not found"

**Solution**: Install Docker Desktop from https://www.docker.com/products/docker-desktop/

### Error: "cannot find package backend_v3/infrastructure"

**Solution**: Run from the project root directory:
```bash
cd C:\Users\pradord\Documents\Projects\imensiah_new\backend_v3
go run integration_tests/generate_coimma_pdf.go
```
